# Download notebooks

All lesson **code is included in the lesson pages** in the docs. These Jupyter notebooks contain the same content so you can **download and run them in your own environment**.

| Lesson | File | Description |
|--------|------|-------------|
| 1. STAC | `01-stac-discovery.ipynb` | Search a STAC catalog and inspect items/assets |
| 2. COG | `02-cog-streaming.ipynb` | Open a COG from URL and read a window |
| 3. xarray | `03-xarray-datacube.ipynb` | Build and slice a small data cube |
| 4. rioxarray | `04-rioxarray.ipynb` | Open a COG with rioxarray, clip, reproject |
| 5. Dask | `05-dask-analytics.ipynb` | Chunked NDVI and lazy reduction |
| 6. Workflow | `06-end-to-end.ipynb` | STAC → COG → xarray → Dask pipeline |

Notebooks are in the `notebooks/` directory. After installing dependencies, open them in your preferred notebook environment.
