# Download notebooks

All lesson **code is included in the lesson pages** in the docs. The Jupyter notebooks contain the same content and can be downloaded and run locally.

https://github.com/amanchry/scalable-raster-analytics/tree/main/notebooks


| Lesson | File | Description |
|--------|------|-------------|
| 1. STAC & COG | `01-stac-cog.ipynb` | Search STAC, sign URLs, stream a COG window |
| 2. xarray | `02-xarray-datacube.ipynb` | Build and slice a small data cube |
| 3. rioxarray | `03-rioxarray.ipynb` | Open DEM and Sentinel-2 COGs, clip, reproject |
| 4. Dask | `04-dask-analytics.ipynb` | Chunked NDVI and lazy reduction |
| 5. Workflow | `05-end-to-end.ipynb` | STAC → COG → xarray → Dask pipeline |

Notebooks are in the `notebooks/` directory. After installing dependencies, open them in a Jupyter environment.
