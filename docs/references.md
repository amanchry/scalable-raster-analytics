# References & further reading

## Specifications & standards

- [STAC Specification](https://stacspec.org/) — SpatioTemporal Asset Catalog.
- [Cloud Optimized GeoTIFF](https://www.cogeo.org/) — COG overview and best practices.
- [xarray Documentation](https://docs.xarray.dev/) — Data structures and user guide.
- [Dask Documentation](https://docs.dask.org/) — Parallel computing with blocked algorithms.

## Python libraries

- [pystac-client](https://pystac-client.readthedocs.io/) — STAC API client.
- [rioxarray](https://corteva.github.io/rioxarray/) — Geospatial extension for xarray.
- [rasterio](https://rasterio.readthedocs.io/) — Raster I/O (used by rioxarray).
- [planetary-computer](https://planetarycomputer.microsoft.com/docs/) — Microsoft Planetary Computer SDK and signing.

## Catalogs & data

- [Microsoft Planetary Computer](https://planetarycomputer.microsoft.com/) — STAC API and datasets (Sentinel-2, Landsat, etc.).
- [Earth Search (Element 84)](https://earth-search.aws.element84.com/v1/api.html) — STAC API over AWS.
